# Cloud Infrastructure & DevOps Project

## 📌 Overview
This project demonstrates a basic DevOps workflow using Git, GitHub, and GitHub Actions. It focuses on version control, repository management, and Continuous Integration (CI) practices.

## 🛠️ Technologies Used
- Git
- GitHub
- GitHub Actions
- VS Code
- YAML

## 🚀 Features
- Version control using Git
- Code repository management using GitHub
- Automated CI workflow using GitHub Actions
- Structured project organization

## ⚙️ CI Pipeline
The project includes a GitHub Actions workflow that automatically runs when changes are pushed to the main branch.

Workflow steps:
1. Checkout the repository
2. Verify the project
3. Complete the CI process successfully
